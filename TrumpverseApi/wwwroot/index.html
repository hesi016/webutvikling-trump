TrumpVerse API Documentation

Explore the resources in the TrumpVerse API to manage staff and retrieve their details.

REST

Base URL: http://localhost:5027/api

The base URL contains information about all available API resources. All requests are GET requests and go over HTTPS. All responses will return data in JSON format.

{
  "staff": "http://localhost:5027/api/Staff",
  "staffById": "http://localhost:5027/api/Staff/{id}",
  "staffByStatus": "http://localhost:5027/api/Staff/status/{status}"
}

There are currently three available resources:

  • Staff: Retrieve all staff members.
  • Staff by ID: Retrieve details of a specific staff member by ID.
  • Staff by Status: Retrieve staff members filtered by their status.

GET /api/Staff/{id}

Retrieve details of a specific staff member by their ID.

Path Parameters

  • id: (required, integer) The ID of the staff member.

Response Example

{
  "id": 2,
  "firstName": "Brooke",
  "lastName": "Rollins",
  "position": "Secretary of Agriculture",
  "status": "active",
  "profileImage": "Brooke_Rollins.jpg"
}

GET /api/Staff/status/{status}

Retrieve staff members filtered by their status.

Path Parameters

  • status: (required, string) The status to filter staff by (Active, Inactive).
